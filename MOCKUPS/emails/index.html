Shared anatomy & notes

  • Anatomy: hidden preheader · bubble mark + mono meta strip · serif heading · body copy · primary CTA · plain-text fallback URL · expiry note · "didn't request this" callout · footer.
  • Single primary action per email; the fallback URL is the only secondary path.
  • Expiry is 30 minutes (demo assumption); reset links are additionally single-use.
  • SVG mark renders in browsers but not in most email clients — export a PNG for production sends.
  • Copy is demo data extending the Kai Rebane persona; swap names, addresses, and tokens at send time.
