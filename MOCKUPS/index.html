Language identity: each language carries a flag-derived tint on translation-card tops and column headers — EN · DE · ES · EE. All tokens are CSS variables, ready for dark mode later.

Type — serif display, sans UI, mono data

Iowan / Charter — word titles, page headings System sans — labels, body, table data SF Mono — counts, cases, badges, 6/8

Base 14px UI text, 36px controls, 40px table rows, 4px spacing grid. Density comes from structure (grids, tight rows), never from shrinking text below 12px.
