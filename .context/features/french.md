# French (the fifth language)

## Summary

French is the fifth language of Ladu. A person can learn French words and can use the whole interface in French. Every word can have a French translation, with forms for all six parts of speech (noun, verb, adjective, adverb, conjunction, preposition), practice exercises, autocomplete from Wiktionary, an onboarding pool and a demo template. The French text was made by machine and is a first draft: a French teacher reviews it later.

Live spec. It replaces a finished plan (archive record: `.context/archive/2026-10-language-french.md`). Built 2026-10-25 to 2026-10-26 (slices 0 to 12), merged as PR #110, rolled out on staging and production (2026-10-27). Gates: `e2e/tests/language-french-interface.spec.ts`, `language-french-forms.spec.ts`, `autocomplete-j-french-lexicon.spec.ts`.

The field lists and rules of the French forms are in `.context/features/word-forms/forms-french.md`. The checklist that the work produced, and that the next language follows, is `.context/guides/add-language.md`. The coverage research of the French lexicon is `.context/research/french-lexicon-coverage.md`. The review sheets for the French teacher are `.context/research/language-french-review.md` (word forms and practice) and `.context/research/language-french-strings.md` (interface).

Code map: the language tables `backend/lib/languages.ts` and `frontend/src/lib/language.ts` (`LANG_SUFFIX`, `MAX_TRANSLATIONS`), `frontend/src/ts/enums.ts` (`Lang.FR`, `GenderFR`, `VerbGroupFR` …), the form configs in `frontend/src/features/words/form-engine/configs/` (`buildFrConfig` in `verbs.ts`, `adverbs.ts`, `prepositions.ts`; `conjunctions.ts`), 14 locale files `frontend/public/locales/fr/`, `backend/lib/lexicon/selectors/fr.ts`, `backend/services/dictionary/registry.ts` (`withPronominalFallback`), `backend/scripts/onboarding/pool.tsv` (columns `fr`, `fr_gender`), the demo template, `landing/`. No migration: languages are `varchar` values.

## 1. Decisions from the user (2026-10-25)

- **L1. Full language.** French is a language to learn **and** an interface language: 14 `fr/*.json` locale files, emails, landing page. One list keeps both meanings (no split).
- **L2. Scope.** Forms first, then autocomplete (kaikki/Wiktionary) with a coverage check.
- **L3. Consolidate first.** One language module per tier before French is added (no behaviour change).
- **L4. Include the onboarding pool and the demo template** as late slices.
- **L5. Working mode.** Auto mode from phase 0 (2026-10-26). The slice rules in `CLAUDE.md` still apply: overview first, tests with the code, no commits by the assistant.

## 3. Traps for the next language

- A key such as `MAX_TRANSLATIONS` and the `registeredCasesXX` names were hard-coded for four languages in places the first plan missed (S3-1, F3). Search for the other languages in files the branch did not change (guide section 4a).
- The French verb entry in Wiktionary has one conjugation table per use; a pronominal table is not always tagged `reflexive`, so a table is pronominal when its infinitive starts with "se " or "s'" (V5). The plain table is used if there is one.
- A radio value with a digit ("1er groupe") made the form invalid until `buildYupSchema.ts` allowed digits in a radio value (V1).
- The e2e database keeps an older demo template. After a data change, a demo e2e needs a reseed with `--reset`.
