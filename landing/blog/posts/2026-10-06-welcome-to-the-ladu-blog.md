This is the first post of the Ladu blog. It is a **draft**: it is not published
until you remove the `draft: true` line from the top of this file, or replace the
file with a real post.

## How a post works

- One file per post, in `landing/blog/posts/`.
- The file name is `YYYY-MM-DD-slug.md`. The date and the web address come from it.
- The text is Markdown. Images go in `landing/blog/images/` and are used like this:
  `![A short description](images/example.png)`.

See `landing/README.md` for the full steps.
